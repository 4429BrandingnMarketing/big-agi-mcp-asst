# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-06

### Added
- Initial release of Big-AGI MCP Assistant
- Mathematical calculation tool
- Text analysis tool with multiple metrics
- JSON formatting and validation tool
- Timestamp conversion tool
- Base64 encoding/decoding tool
- UUID generation tool
- Text hashing tool (MD5, SHA1, SHA256, SHA512)
- Two resources: capabilities and help documentation
- Full TypeScript implementation
- Comprehensive documentation
- MIT License

### Features
- Full MCP (Model Context Protocol) compliance
- Integration with Big-AGI and other MCP clients
- Stdio-based transport for maximum compatibility
- Error handling and validation
- Graceful shutdown handling
